# Greedify Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native SwiftUI macOS Spotify client (menu-bar popover + main window) that plays audio through a bundled librespot background service, so the official Spotify app is no longer needed.

**Architecture:** Two processes. `Greedify.app` is a menu-bar-only SwiftUI app that does all UI and controls playback only through the Spotify Web API. `librespot` runs as a LaunchAgent (registered with `SMAppService.agent`) and shows up as a Spotify Connect device that plays audio through CoreAudio. All non-UI logic lives in a Swift package, `GreedifyKit`, which has unit tests. The app target holds only SwiftUI views and wiring.

**Tech Stack:** Swift 6, SwiftUI (macOS 15+), Swift Testing, XcodeGen, Spotify Web API (PKCE), LRCLIB, librespot 0.8.0 (Homebrew), ServiceManagement, CoreGraphics event taps.

**Spec:** `docs/superpowers/specs/2026-09-29-greedify-design.md`, with approved mockups in `docs/superpowers/specs/mockups/`.

## Global Constraints

- macOS deployment target 15.0; Swift language mode 6; bundle ID `com.alperen.greedify`.
- Web API: the user's **own client ID only**; never borrow another app's client ID.
- Redirect URI `greedify://callback`, with a loopback fallback only if check C2 fails.
- Scopes: exactly `AuthConfig.defaultScopes` (Task 4). This includes `user-follow-modify`, which `PUT /me/library` requires; the spec's scope list omitted it.
- Search `limit` ≤ 10; library URIs ≤ 40 per request; playlist items ≤ 100 per request.
- Polling `/me/player`: 3 s while the popover or window is open, 15 s otherwise, 60 s during a rate-limit back-off.
- Cache defaults: artwork in RAM 30 MB (options 15/30/60 MB); app disk cache 300 MB (options 100 MB/300 MB/1 GB/2 GB); audio cache Off (options Off/1/2/5 GB).
- Accent colour: light `#17A058`, dark `#34D17C`. Otherwise only system colours, materials and SF Symbols.
- Menu-bar lyric label: at most about 280 pt wide, and at most 48 characters with a tail "…".
- librespot credentials live in `~/Library/Application Support/Greedify/librespot/` (`--system-cache`), separate from the audio cache (`~/Library/Caches/Greedify/librespot-audio/`, `--cache`). Clearing a cache never logs out.
- No modal error alerts: errors appear as non-blocking banners, and are logged with `os.Logger`, subsystem `com.alperen.greedify`.
- Memory target: ≤ 70 MB total (Greedify + librespot) while playing with the window closed.
- Copy: sentence case; buttons say exactly what they do.

## Review Focus

These five situations aren't covered by the automated tests. Each has a manual check in the task where the code first runs:

1. **The Mac wakes after hours asleep.** The access token has expired and the local clock is stale. Expected: the position and track update within a few seconds of waking, with no "login expired" banner. (Task 13, step "Review Focus checks")
2. **Accessibility is granted while Greedify is already running.** Expected: media keys start working without relaunching. (Task 13)
3. **The Mac speaker service is gone** (booted out, crashed repeatedly, or unregistered). Expected: the popover shows "Restart", and Restart brings "Studio Mac" back to the device list. (Task 13)
4. **The network drops mid-song and comes back.** Expected: controls grey out and no error banners pile up; polling resumes by itself. (Task 13)
5. **The user renames the Mac speaker in Settings.** Expected: librespot restarts under the new name, and play with no active device still finds it. (Task 15)

- [ ] **Step 3: Write the token helper**

`scripts/spike/token.py`:

```python
#!/usr/bin/env python3
"""Throwaway (Task 1 checks only): prints a Spotify user access token via PKCE + loopback.

Usage: python3 scripts/spike/token.py <CLIENT_ID>
Needs http://127.0.0.1:8898/callback registered as a redirect URI in the Spotify dashboard.
"""
import base64, hashlib, http.server, json, secrets, sys, urllib.parse, urllib.request, webbrowser

CLIENT_ID = sys.argv[1]
REDIRECT = "http://127.0.0.1:8898/callback"
SCOPES = "user-read-playback-state user-modify-playback-state playlist-read-private"

verifier = secrets.token_urlsafe(64)[:64]
challenge = base64.urlsafe_b64encode(hashlib.sha256(verifier.encode()).digest()).rstrip(b"=").decode()
state = secrets.token_urlsafe(16)
url = "https://accounts.spotify.com/authorize?" + urllib.parse.urlencode(dict(
    client_id=CLIENT_ID, response_type="code", redirect_uri=REDIRECT, code_challenge_method="S256",
    code_challenge=challenge, state=state, scope=SCOPES))

result = {}

class Handler(http.server.BaseHTTPRequestHandler):
    def do_GET(self):
        query = urllib.parse.parse_qs(urllib.parse.urlparse(self.path).query)
        result["code"] = query.get("code", [None])[0]
        result["state"] = query.get("state", [None])[0]
        self.send_response(200)
        self.end_headers()
        self.wfile.write(b"Done. You can close this tab.")

    def log_message(self, *args):
        pass

server = http.server.HTTPServer(("127.0.0.1", 8898), Handler)
webbrowser.open(url)
server.handle_request()
if result.get("state") != state or not result.get("code"):
    sys.exit("Login failed or state mismatch")
body = urllib.parse.urlencode(dict(grant_type="authorization_code", code=result["code"], redirect_uri=REDIRECT,
                                   client_id=CLIENT_ID, code_verifier=verifier)).encode()
token = json.load(urllib.request.urlopen(urllib.request.Request("https://accounts.spotify.com/api/token", data=body)))
print(token["access_token"])
```

`scripts/bundle-librespot.sh`:

```sh
#!/bin/sh
# Xcode post-build step: copies Homebrew's librespot and the launcher into Greedify.app,
# installs the LaunchAgent plist, and signs the nested executables so the app signature stays valid.
set -eu
SRC="${LIBRESPOT_BIN:-}"
if [ -z "$SRC" ]; then
  for candidate in /opt/homebrew/bin/librespot /usr/local/bin/librespot; do
    [ -x "$candidate" ] && SRC="$candidate" && break
  done
fi
if [ -z "$SRC" ] || [ ! -x "$SRC" ]; then
  echo "error: librespot not found. Run: brew install librespot (or set LIBRESPOT_BIN)" >&2
  exit 1
fi
MACOS_DIR="$TARGET_BUILD_DIR/$EXECUTABLE_FOLDER_PATH"
AGENTS_DIR="$TARGET_BUILD_DIR/$CONTENTS_FOLDER_PATH/Library/LaunchAgents"
mkdir -p "$AGENTS_DIR"
cp -f "$(realpath "$SRC")" "$MACOS_DIR/librespot"
cp -f "$SRCROOT/App/Resources/greedify-speaker" "$MACOS_DIR/greedify-speaker"
chmod 755 "$MACOS_DIR/librespot" "$MACOS_DIR/greedify-speaker"
cp -f "$SRCROOT/App/Resources/com.alperen.greedify.librespot.plist" "$AGENTS_DIR/"
codesign --force --sign "${EXPANDED_CODE_SIGN_IDENTITY:--}" "$MACOS_DIR/librespot" "$MACOS_DIR/greedify-speaker"
```

import Foundation

public enum SpotifyError: Error, Equatable, Sendable {
    /// No tokens stored; the user has never logged in (or logged out).
    case notAuthenticated
    /// The refresh token is expired or revoked; the user must log in again.
    case reauthRequired
    case rateLimited(retryAfter: TimeInterval, quotaExceeded: Bool)
    case noActiveDevice
    case forbidden(String)
    case notFound
    case http(status: Int, message: String)
    case transport(String)
    case decoding(String)

    /// Builds an error from a non-2xx Web API response.
    /// Body shape: `{"error":{"status":404,"message":"...","reason":"NO_ACTIVE_DEVICE"}}`.
    public static func from(status: Int, headers: [AnyHashable: Any], body: Data) -> SpotifyError {
        struct Envelope: Decodable {
            struct Inner: Decodable { let message: String?; let reason: String? }
            let error: Inner?
        }
        let inner = (try? JSONDecoder().decode(Envelope.self, from: body))?.error
        let message = inner?.message ?? ""
        let reason = inner?.reason ?? ""
        switch status {
        case 429:
            let header = headers.first { "\($0.key)".lowercased() == "retry-after" }?.value
            let seconds = TimeInterval("\(header ?? "")") ?? 5
            return .rateLimited(retryAfter: seconds, quotaExceeded: reason == "QUOTA_EXCEEDED" || message.contains("QUOTA_EXCEEDED"))
        case 404 where reason == "NO_ACTIVE_DEVICE" || message.localizedCaseInsensitiveContains("no active device"):
            return .noActiveDevice
        case 404:
            return .notFound
        case 403:
            return .forbidden(message)
        default:
            return .http(status: status, message: message)
        }
    }

    /// Short text for the non-blocking banner.
    public var bannerText: String {
        switch self {
        case .notAuthenticated, .reauthRequired: "Spotify login expired. Log in again."
        case .rateLimited: "Spotify is limiting requests. Retrying shortly."
        case .noActiveDevice: "No Spotify device is available."
        case .forbidden: "You can only change playlists you own"
        case .notFound: "Spotify couldn't find that item."
        case .http(let status, _): "Spotify returned an error (\(status))."
        case .transport: "Can't reach Spotify. Check your connection."
        case .decoding: "Spotify sent a response Greedify can't read."
        }
    }
}

/// The single seam between Greedify and the network. Tests swap in `StubTransport`.
public protocol HTTPTransport: Sendable {

public struct URLSessionTransport: HTTPTransport {
    let session: URLSession
    public init(session: URLSession = .shared) { self.session = session }

    public func send(_ request: URLRequest) async throws -> (Data, HTTPURLResponse) {
        do {
            let (data, response) = try await session.data(for: request)
            guard let http = response as? HTTPURLResponse else {
                throw SpotifyError.transport("Not an HTTP response")
            }
            return (data, http)
        } catch let error as SpotifyError {
            throw error
        } catch {
            throw SpotifyError.transport(error.localizedDescription)
        }
    }
}

import CryptoKit
import Foundation

public enum PKCE {
    static let alphabet = Array("ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-._~")

    /// A random code verifier (43–128 chars from the unreserved set, RFC 7636).
    public static func makeVerifier(length: Int = 64) -> String {
        precondition((43...128).contains(length))
        var rng = SystemRandomNumberGenerator()
        return String((0..<length).map { _ in alphabet.randomElement(using: &rng)! })
    }

    /// `BASE64URL(SHA256(verifier))` without padding.
    public static func challenge(for verifier: String) -> String {
        Data(SHA256.hash(data: Data(verifier.utf8))).base64URLEncoded()
    }

    public static func makeState() -> String { makeVerifier(length: 43) }
}

extension Data {
    func base64URLEncoded() -> String {
        base64EncodedString()
            .replacingOccurrences(of: "+", with: "-")
            .replacingOccurrences(of: "/", with: "_")
            .replacingOccurrences(of: "=", with: "")
    }
}

import Foundation
import Security

public struct Tokens: Codable, Equatable, Sendable {
    public var accessToken: String
    public var refreshToken: String
    public var expiresAt: Date
    public var scope: String

    public init(accessToken: String, refreshToken: String, expiresAt: Date, scope: String) {
        self.accessToken = accessToken; self.refreshToken = refreshToken
        self.expiresAt = expiresAt; self.scope = scope
    }

    /// True when the access token expires within `margin` seconds.
    public func isExpired(now: Date, margin: TimeInterval = 60) -> Bool {
        expiresAt.timeIntervalSince(now) < margin
    }
}

public protocol TokenStore: Sendable {
    func load() -> Tokens?
    func save(_ tokens: Tokens)
    func clear()
}

public final class InMemoryTokenStore: TokenStore, @unchecked Sendable {
    private let lock = NSLock()
    private var tokens: Tokens?
    public init(_ tokens: Tokens? = nil) { self.tokens = tokens }
    public func load() -> Tokens? { lock.withLock { tokens } }
    public func save(_ tokens: Tokens) { lock.withLock { self.tokens = tokens } }
    public func clear() { lock.withLock { tokens = nil } }
}

/// Stores tokens as one JSON blob in the login keychain.
public struct KeychainTokenStore: TokenStore {
    let service: String
    let account = "spotify-tokens"
    public init(service: String = "com.alperen.greedify") { self.service = service }

    private var query: [String: Any] {
        [kSecClass as String: kSecClassGenericPassword,
         kSecAttrService as String: service,
         kSecAttrAccount as String: account]
    }

    public func load() -> Tokens? {
        var q = query
        q[kSecReturnData as String] = true
        q[kSecMatchLimit as String] = kSecMatchLimitOne
        var out: CFTypeRef?
        guard SecItemCopyMatching(q as CFDictionary, &out) == errSecSuccess, let data = out as? Data else { return nil }
        return try? JSONDecoder().decode(Tokens.self, from: data)
    }

    public func save(_ tokens: Tokens) {
        guard let data = try? JSONEncoder().encode(tokens) else { return }
        let status = SecItemUpdate(query as CFDictionary, [kSecValueData as String: data] as CFDictionary)
        if status == errSecItemNotFound {
            var q = query
            q[kSecValueData as String] = data
            q[kSecAttrAccessible as String] = kSecAttrAccessibleAfterFirstUnlock
            SecItemAdd(q as CFDictionary, nil)
        }
    }

    public func clear() { SecItemDelete(query as CFDictionary) }
}

import Foundation

public struct AuthConfig: Sendable, Equatable {
    public var clientID: String
    public var redirectURI: URL
    public var scopes: [String]

    public static let defaultScopes = [
        "user-read-playback-state", "user-modify-playback-state", "user-read-currently-playing",
        "user-library-read", "user-library-modify",
        "playlist-read-private", "playlist-read-collaborative",
        "playlist-modify-private", "playlist-modify-public",
        "user-follow-read", "user-follow-modify",
    ]

    public init(clientID: String, redirectURI: URL, scopes: [String] = AuthConfig.defaultScopes) {
        self.clientID = clientID; self.redirectURI = redirectURI; self.scopes = scopes
    }
}

public enum AuthError: Error, Equatable, Sendable {
    case stateMismatch
    case denied(String)
    case missingCode
}

/// Authorization Code + PKCE against accounts.spotify.com. Stateless; tokens live in a `TokenStore`.
public struct AuthService: Sendable {
    public let config: AuthConfig
    let transport: HTTPTransport
    let now: @Sendable () -> Date
    static let tokenURL = URL(string: "https://accounts.spotify.com/api/token")!

    public init(config: AuthConfig, transport: HTTPTransport, now: @escaping @Sendable () -> Date = Date.init) {
        self.config = config; self.transport = transport; self.now = now
    }

    public func authorizationURL(verifier: String, state: String) -> URL {
        var c = URLComponents(string: "https://accounts.spotify.com/authorize")!
        c.queryItems = [
            .init(name: "client_id", value: config.clientID),
            .init(name: "response_type", value: "code"),
            .init(name: "redirect_uri", value: config.redirectURI.absoluteString),
            .init(name: "code_challenge_method", value: "S256"),
            .init(name: "code_challenge", value: PKCE.challenge(for: verifier)),
            .init(name: "state", value: state),
            .init(name: "scope", value: config.scopes.joined(separator: " ")),
        ]
        return c.url!
    }

    /// Extracts the authorization code from the redirect URL.
    public static func code(from callback: URL, expectedState: String) throws -> String {
        let items = URLComponents(url: callback, resolvingAgainstBaseURL: false)?.queryItems ?? []
        func value(_ name: String) -> String? { items.first { $0.name == name }?.value }
        if let error = value("error") { throw AuthError.denied(error) }
        guard value("state") == expectedState else { throw AuthError.stateMismatch }
        guard let code = value("code"), !code.isEmpty else { throw AuthError.missingCode }
        return code
    }

    public func exchange(code: String, verifier: String) async throws -> Tokens {
        let response = try await postToken([
            "grant_type": "authorization_code",
            "code": code,
            "redirect_uri": config.redirectURI.absoluteString,
            "client_id": config.clientID,
            "code_verifier": verifier,
        ])
        guard let refresh = response.refreshToken else { throw SpotifyError.decoding("No refresh_token in token response") }
        return Tokens(accessToken: response.accessToken, refreshToken: refresh,
                      expiresAt: now().addingTimeInterval(response.expiresIn), scope: response.scope ?? "")
    }

    /// Spotify may or may not rotate the refresh token; keep the old one if none is returned.
    public func refresh(_ tokens: Tokens) async throws -> Tokens {
        let response = try await postToken([
            "grant_type": "refresh_token",
            "refresh_token": tokens.refreshToken,
            "client_id": config.clientID,
        ])
        return Tokens(accessToken: response.accessToken, refreshToken: response.refreshToken ?? tokens.refreshToken,
                      expiresAt: now().addingTimeInterval(response.expiresIn), scope: response.scope ?? tokens.scope)
    }

    struct TokenResponse: Decodable {
        let accessToken: String
        let refreshToken: String?
        let expiresIn: TimeInterval
        let scope: String?
    }

    private func postToken(_ form: [String: String]) async throws -> TokenResponse {
        var request = URLRequest(url: Self.tokenURL)
        request.httpMethod = "POST"
        request.setValue("application/x-www-form-urlencoded", forHTTPHeaderField: "Content-Type")
        request.httpBody = Self.formEncode(form).data(using: .utf8)
        let (data, http) = try await transport.send(request)
        guard (200..<300).contains(http.statusCode) else {
            // `invalid_grant` = refresh token expired/revoked (e.g. the 6-month limit).
            if http.statusCode == 400, String(decoding: data, as: UTF8.self).contains("invalid_grant") {
                throw SpotifyError.reauthRequired
            }
            throw SpotifyError.http(status: http.statusCode, message: String(decoding: data, as: UTF8.self))
        }
        do { return try SpotifyJSON.decoder.decode(TokenResponse.self, from: data) }
        catch { throw SpotifyError.decoding("\(error)") }
    }

    static func formEncode(_ form: [String: String]) -> String {
        var allowed = CharacterSet.alphanumerics
        allowed.insert(charactersIn: "-._~")
        return form.sorted { $0.key < $1.key }
            .map { "\($0.key)=\($0.value.addingPercentEncoding(withAllowedCharacters: allowed) ?? $0.value)" }
            .joined(separator: "&")
    }
}

import Foundation

/// The real Web API client. An actor so token refresh happens at most once at a time.
public actor LiveSpotifyAPI: SpotifyAPI {
    static let base = URL(string: "https://api.spotify.com/v1")!

    let auth: AuthService
    let tokens: TokenStore
    let transport: HTTPTransport
    let now: @Sendable () -> Date
    private var refreshTask: Task<Tokens, Error>?
    /// While set and in the future, requests fail fast with `.rateLimited`.
    private(set) var backoffUntil: Date?
    private var backoffQuota = false

    public init(auth: AuthService, tokens: TokenStore, transport: HTTPTransport,
                now: @escaping @Sendable () -> Date = Date.init) {
        self.auth = auth; self.tokens = tokens; self.transport = transport; self.now = now
    }

    // MARK: Request pipeline

    enum Method: String { case get = "GET", put = "PUT", post = "POST", delete = "DELETE" }

    func makeURL(_ path: String, _ query: [String: String?]) -> URL {
        var c = URLComponents(url: Self.base.appendingPathComponent(path), resolvingAgainstBaseURL: false)!
        let items = query.compactMap { k, v in v.map { URLQueryItem(name: k, value: $0) } }.sorted { $0.name < $1.name }
        c.queryItems = items.isEmpty ? nil : items
        // `+` would be read as a space by some servers; Spotify URIs use `:` which is fine.
        c.percentEncodedQuery = c.percentEncodedQuery?.replacingOccurrences(of: "+", with: "%2B")
        return c.url!
    }

    private func validAccessToken() async throws -> String {
        guard let current = tokens.load() else { throw SpotifyError.notAuthenticated }
        if !current.isExpired(now: now()) { return current.accessToken }
        return try await refreshed(current).accessToken
    }

    private func refreshed(_ current: Tokens) async throws -> Tokens {
        if let refreshTask { return try await refreshTask.value }
        let task = Task { [auth] in try await auth.refresh(current) }
        refreshTask = task
        defer { refreshTask = nil }
        do {
            let fresh = try await task.value
            tokens.save(fresh)
            return fresh
        } catch SpotifyError.reauthRequired {
            tokens.clear()
            throw SpotifyError.reauthRequired
        }
    }

    /// Sends a request; on 401 refreshes once and retries; maps errors to `SpotifyError`.
    func send(_ method: Method, _ path: String, query: [String: String?] = [:], json: Any? = nil) async throws -> Data? {
        if let until = backoffUntil, until > now() {
            throw SpotifyError.rateLimited(retryAfter: until.timeIntervalSince(now()), quotaExceeded: backoffQuota)
        }
        var attempt = 0
        while true {
            var request = URLRequest(url: makeURL(path, query))
            request.httpMethod = method.rawValue
            request.setValue("Bearer \(try await validAccessToken())", forHTTPHeaderField: "Authorization")
            if let json {
                request.setValue("application/json", forHTTPHeaderField: "Content-Type")
                request.httpBody = try JSONSerialization.data(withJSONObject: json)
            } else if method != .get {
                request.setValue("0", forHTTPHeaderField: "Content-Length")
            }
            let (data, http) = try await transport.send(request)
            switch http.statusCode {
            case 204: return nil
            case 200..<300: return data.isEmpty ? nil : data
            case 401 where attempt == 0:
                attempt += 1
                if let current = tokens.load() { _ = try await refreshed(current) } else { throw SpotifyError.notAuthenticated }
            case 401:
                throw SpotifyError.reauthRequired
            default:
                let error = SpotifyError.from(status: http.statusCode, headers: http.allHeaderFields, body: data)
                if case .rateLimited(let after, let quota) = error {
                    backoffUntil = now().addingTimeInterval(after)
                    backoffQuota = quota
                }
                throw error
            }
        }
    }

    func get<T: Decodable>(_ type: T.Type, _ path: String, query: [String: String?] = [:]) async throws -> T {
        guard let data = try await send(.get, path, query: query) else { throw SpotifyError.decoding("Empty body for \(path)") }
        return try decode(type, data, path)
    }

    func decode<T: Decodable>(_ type: T.Type, _ data: Data, _ path: String) throws -> T {
        do { return try SpotifyJSON.decoder.decode(type, from: data) }
        catch { throw SpotifyError.decoding("\(path): \(error)") }
    }

import Foundation

/// Advances the playback position locally between polls.
public struct PlaybackClock: Equatable, Sendable {
    public private(set) var anchorMs: Int
    public private(set) var anchorDate: Date
    public private(set) var isPlaying: Bool
    public private(set) var durationMs: Int

    public init(progressMs: Int = 0, durationMs: Int = 0, isPlaying: Bool = false, at date: Date = Date()) {
        anchorMs = progressMs; anchorDate = date; self.isPlaying = isPlaying; self.durationMs = durationMs
    }

    /// Re-anchors to a fresh server reading.
    public mutating func sync(progressMs: Int, durationMs: Int, isPlaying: Bool, at date: Date) {
        anchorMs = progressMs; anchorDate = date; self.isPlaying = isPlaying; self.durationMs = durationMs
    }

    public mutating func setPlaying(_ playing: Bool, at date: Date) {
        anchorMs = positionMs(at: date); anchorDate = date; isPlaying = playing
    }

    public mutating func seek(toMs ms: Int, at date: Date) {
        anchorMs = max(0, min(ms, durationMs)); anchorDate = date
    }

    public func positionMs(at date: Date) -> Int {
        guard isPlaying else { return anchorMs }
        let elapsed = Int(date.timeIntervalSince(anchorDate) * 1000)
        return max(0, min(anchorMs + elapsed, durationMs))
    }
}

public final class PlayerStore {
    public private(set) var state: PlaybackState?
    public private(set) var devices: [Device] = []
    public private(set) var clock = PlaybackClock()
    public private(set) var lastError: SpotifyError?
    public private(set) var isRateLimited = false
    /// Set by the UI: true while the popover or main window is open.
    public var uiVisible = false {
        didSet { if uiVisible && !oldValue { Task { await refresh() } } }
    }
    /// Name of the librespot device, used when no device is active.
    public var localDeviceName: String

    let api: SpotifyAPI
    let now: @Sendable () -> Date
    private var pollTask: Task<Void, Never>?
    /// Last context played, remembered so media keys can resume it with no active device.
    public private(set) var lastContextURI: String?

    public init(api: SpotifyAPI, localDeviceName: String, now: @escaping @Sendable () -> Date = Date.init) {
        self.api = api; self.localDeviceName = localDeviceName; self.now = now
    }

    public var track: Track? { state?.item }
    public var isPlaying: Bool { state?.isPlaying ?? false }
    public var activeDevice: Device? { state?.device ?? devices.first(where: \.isActive) }
    public func positionMs(at date: Date) -> Int { clock.positionMs(at: date) }

    // MARK: Polling

    public func startPolling() {
        guard pollTask == nil else { return }
        pollTask = Task { [weak self] in
            while !Task.isCancelled {
                guard let self else { return }
                await self.refresh()
                let interval = PollInterval.next(uiVisible: self.uiVisible, backingOff: self.isRateLimited)
                try? await Task.sleep(for: .seconds(interval))
            }
        }
    }

    public func stopPolling() { pollTask?.cancel(); pollTask = nil }

    public func refresh() async {
        do {
            let fresh = try await api.playbackState()
            apply(fresh)
            isRateLimited = false
            if case .rateLimited? = lastError { lastError = nil }
        } catch let error as SpotifyError {
            record(error)
        } catch {
            record(.transport("\(error)"))
        }
    }

    func apply(_ fresh: PlaybackState?) {
        state = fresh
        if let context = fresh?.context?.uri { lastContextURI = context }
        clock.sync(progressMs: fresh?.progressMs ?? 0, durationMs: fresh?.item?.durationMs ?? 0,
                   isPlaying: fresh?.isPlaying ?? false, at: now())
    }

    func record(_ error: SpotifyError) {
        lastError = error
        if case .rateLimited = error { isRateLimited = true }
    }

    public func clearError() { lastError = nil }

    public func refreshDevices() async {
        do { devices = try await api.devices() } catch let e as SpotifyError { record(e) } catch {}
    }

    // MARK: Commands

    /// Runs a command, then re-polls. `NO_ACTIVE_DEVICE` moves playback to the Mac and retries once.
    func perform(_ command: @escaping @Sendable (String?) async throws -> Void) async {
        do {
            try await command(nil)
        } catch SpotifyError.noActiveDevice {
            do {
                guard let id = try await localDeviceID() else { record(.noActiveDevice); return }
                try await command(id)
            } catch let e as SpotifyError { record(e) } catch {}
        } catch let e as SpotifyError {
            record(e)
        } catch {}
        await refresh()
    }

    func localDeviceID() async throws -> String? {
        let list = try await api.devices()
        devices = list
        return list.first { $0.name == localDeviceName }?.id
    }

    /// Play/pause. With no active device, plays the last context (or resumes) on the Mac.
    public func togglePlayPause() async {
        if isPlaying {
            clock.setPlaying(false, at: now())
            await perform { [api] _ in try await api.pause() }
        } else {
            clock.setPlaying(true, at: now())
            let fallback = lastContextURI
            await perform { [api] device in
                if let device {
                    try await api.play(fallback.map { PlayRequest.context($0) } ?? .resume, deviceID: device)
                } else {
                    try await api.play(.resume, deviceID: nil)
                }
            }
        }
    }

    public func next() async { await perform { [api] _ in try await api.next() } }
    public func previous() async { await perform { [api] _ in try await api.previous() } }

    public func seek(toMs ms: Int) async {
        clock.seek(toMs: ms, at: now())
        await perform { [api] _ in try await api.seek(toMs: ms) }
    }

    public func setVolume(_ percent: Int) async { await perform { [api] _ in try await api.setVolume(percent) } }
    public func setShuffle(_ on: Bool) async { await perform { [api] _ in try await api.setShuffle(on) } }
    public func setRepeat(_ mode: RepeatMode) async { await perform { [api] _ in try await api.setRepeat(mode) } }

    public func play(_ request: PlayRequest) async {
        if let context = request.contextURI { lastContextURI = context }
        await perform { [api] device in try await api.play(request, deviceID: device) }
    }

    /// Song radio (spec §4.6): play only this track; autoplay continues with similar songs.
    public func startRadio(trackURI: String) async { await play(.tracks([trackURI])) }

    /// Up next, for the player bar's queue popover.
    public private(set) var upNext: [Track] = []

    public func refreshQueue() async {
        do { upNext = try await api.queue().queue } catch let e as SpotifyError { record(e) } catch {}
    }

    public func addToQueue(uri: String) async { await perform { [api] _ in try await api.addToQueue(uri: uri) } }

    public func transfer(to device: Device) async {
        guard let id = device.id else { return }
        await perform { [api] _ in try await api.transferPlayback(to: id, play: true) }
    }
}

```swift
import CryptoKit
import Foundation

/// Size-capped disk cache with least-recently-used eviction.
/// Recency is the file modification date, bumped on every read.
public actor DataCache {
    public let directory: URL
    public private(set) var limitBytes: Int
    let fm = FileManager.default

    public init(directory: URL, limitBytes: Int) {
        self.directory = directory
        self.limitBytes = limitBytes
        try? FileManager.default.createDirectory(at: directory, withIntermediateDirectories: true)
    }

    func fileURL(for key: String) -> URL {
        let name = SHA256.hash(data: Data(key.utf8)).map { String(format: "%02x", $0) }.joined()
        return directory.appendingPathComponent(name)
    }

    public func data(for key: String) -> Data? {
        let url = fileURL(for: key)
        guard let data = try? Data(contentsOf: url) else { return nil }
        try? fm.setAttributes([.modificationDate: Date()], ofItemAtPath: url.path)
        return data
    }

    public func store(_ data: Data, for key: String) {
        try? data.write(to: fileURL(for: key), options: .atomic)
        evictIfNeeded()
    }

    public func value<T: Decodable>(_ type: T.Type, for key: String) -> T? {
        data(for: key).flatMap { try? JSONDecoder().decode(type, from: $0) }
    }

    public func store<T: Encodable>(_ value: T, for key: String) {
        if let data = try? JSONEncoder().encode(value) { store(data, for: key) }
    }

    public func remove(_ key: String) { try? fm.removeItem(at: fileURL(for: key)) }

    public func setLimit(_ bytes: Int) {
        limitBytes = bytes
        evictIfNeeded()
    }

    struct Entry { let url: URL; let size: Int; let date: Date }

    func entries() -> [Entry] {
        let keys: [URLResourceKey] = [.fileSizeKey, .contentModificationDateKey]
        let urls = (try? fm.contentsOfDirectory(at: directory, includingPropertiesForKeys: keys)) ?? []
        return urls.compactMap { url in
            guard let v = try? url.resourceValues(forKeys: Set(keys)) else { return nil }
            return Entry(url: url, size: v.fileSize ?? 0, date: v.contentModificationDate ?? .distantPast)
        }
    }

    public func sizeBytes() -> Int { entries().reduce(0) { $0 + $1.size } }

    /// Deletes oldest-used files until the total is within the limit.
    public func evictIfNeeded() {
        var list = entries()
        var total = list.reduce(0) { $0 + $1.size }
        guard total > limitBytes else { return }
        list.sort { $0.date < $1.date }
        for entry in list where total > limitBytes {
            try? fm.removeItem(at: entry.url)
            total -= entry.size
        }
    }

    public func clear() {
        for entry in entries() { try? fm.removeItem(at: entry.url) }
    }
}

import AppKit
import Foundation

/// Artwork: decoded images in RAM (`NSCache`, cost = decoded bytes) backed by the disk `DataCache`.
public final class ImageCache: @unchecked Sendable {
    let memory = NSCache<NSURL, NSImage>()
    let disk: DataCache
    let transport: HTTPTransport

    public init(disk: DataCache, transport: HTTPTransport, memoryLimitBytes: Int) {
        self.disk = disk
        self.transport = transport
        memory.totalCostLimit = memoryLimitBytes
    }

    public func setMemoryLimit(_ bytes: Int) { memory.totalCostLimit = bytes }
    public func clearMemory() { memory.removeAllObjects() }

    static func cost(of image: NSImage) -> Int {
        let rep = image.representations.first
        let w = rep?.pixelsWide ?? Int(image.size.width)
        let h = rep?.pixelsHigh ?? Int(image.size.height)
        return max(1, w * h * 4)
    }

    public func cached(_ url: URL) -> NSImage? { memory.object(forKey: url as NSURL) }

    public func image(for url: URL) async -> NSImage? {
        if let hit = cached(url) { return hit }
        let key = "art:\(url.absoluteString)"
        var data = await disk.data(for: key)
        if data == nil {
            guard let (fetched, http) = try? await transport.send(URLRequest(url: url)),
                  (200..<300).contains(http.statusCode) else { return nil }
            await disk.store(fetched, for: key)
            data = fetched
        }
        guard let data, let image = NSImage(data: data) else { return nil }
        memory.setObject(image, forKey: url as NSURL, cost: Self.cost(of: image))
        return image
    }
}

/// A Daily Mix (or any playlist) the user pasted by link. Played by URI; its tracks can't be listed.
public struct MixLink: Codable, Hashable, Sendable, Identifiable {
    public let uri: String
    public var name: String
    public var id: String { uri }

        return "spotify:playlist:\(parts[i + 1])"

        s.count == 22 && s.allSatisfy { $0.isASCII && ($0.isLetter || $0.isNumber) }

/// Search with a 300 ms debounce and per-group "Show more" (10 results per page, Spotify's cap).
@MainActor @Observable
public final class SearchStore {
    public var query = "" { didSet { if query != oldValue { schedule() } } }
    public private(set) var tracks: [Track] = []
    public private(set) var albums: [Album] = []
    public private(set) var artists: [Artist] = []
    public private(set) var playlists: [Playlist] = []
    public private(set) var hasMore: [SearchType: Bool] = [:]
    public private(set) var isSearching = false
    public private(set) var lastError: SpotifyError?

    let api: SpotifyAPI
    let debounce: Duration
    static let pageSize = 10
    private var pending: Task<Void, Never>?

    public init(api: SpotifyAPI, debounce: Duration = .milliseconds(300)) { self.api = api; self.debounce = debounce }

    func schedule() {
        pending?.cancel()
        let q = query.trimmingCharacters(in: .whitespaces)
        guard !q.isEmpty else { reset(); return }
        pending = Task { [debounce] in
            try? await Task.sleep(for: debounce)
            guard !Task.isCancelled else { return }
            await self.search(q)
        }
    }

    func reset() { tracks = []; albums = []; artists = []; playlists = []; hasMore = [:] }

    /// Waits for the in-flight debounced search (used by tests).
    public func settle() async { await pending?.value }

    func search(_ q: String) async {
        isSearching = true
        defer { isSearching = false }
        do {
            let r = try await api.search(q, types: SearchType.allCases, offset: 0, limit: Self.pageSize)
            guard q == query.trimmingCharacters(in: .whitespaces) else { return } // a newer query won
            tracks = r.tracks?.items ?? []; albums = r.albums?.items ?? []
            artists = r.artists?.items ?? []; playlists = r.playlists?.items ?? []
            hasMore = [.track: r.tracks?.hasMore ?? false, .album: r.albums?.hasMore ?? false,
                       .artist: r.artists?.hasMore ?? false, .playlist: r.playlists?.hasMore ?? false]
            lastError = nil
        } catch let e as SpotifyError { lastError = e } catch {}
    }

    public func showMore(_ type: SearchType) async {
        let q = query.trimmingCharacters(in: .whitespaces)
        let offset = switch type {
        case .track: tracks.count
        case .album: albums.count
        case .artist: artists.count
        case .playlist: playlists.count
        }
        do {
            let r = try await api.search(q, types: [type], offset: offset, limit: Self.pageSize)
            switch type {
            case .track: tracks += r.tracks?.items ?? []; hasMore[type] = r.tracks?.hasMore ?? false
            case .album: albums += r.albums?.items ?? []; hasMore[type] = r.albums?.hasMore ?? false
            case .artist: artists += r.artists?.items ?? []; hasMore[type] = r.artists?.hasMore ?? false
            case .playlist: playlists += r.playlists?.items ?? []; hasMore[type] = r.playlists?.hasMore ?? false
            }
        } catch let e as SpotifyError { lastError = e } catch {}
    }
}

import Foundation

public struct LyricLine: Equatable, Sendable, Identifiable {
    public let timeMs: Int
    public let text: String
    public var id: Int { timeMs }
    public init(timeMs: Int, text: String) { self.timeMs = timeMs; self.text = text }
    /// Empty lines in LRC mark instrumental gaps.
    public var isGap: Bool { text.trimmingCharacters(in: .whitespaces).isEmpty }
}

public enum Lyrics: Equatable, Sendable {
    case synced([LyricLine])
    case plain(String)
    case none
}

public enum LRCParser {
    /// Parses `[mm:ss.xx] text` lines. A line may carry several timestamps. Metadata tags are ignored.
    public static func parse(_ lrc: String) -> [LyricLine] {
        var lines: [LyricLine] = []
        for raw in lrc.split(whereSeparator: \.isNewline) {
            var rest = Substring(raw)
            var times: [Int] = []
            while rest.hasPrefix("["), let close = rest.firstIndex(of: "]") {
                let tag = rest[rest.index(after: rest.startIndex)..<close]
                if let ms = timestamp(tag) { times.append(ms) }
                rest = rest[rest.index(after: close)...]
            }
            let text = rest.trimmingCharacters(in: .whitespaces)
            lines += times.map { LyricLine(timeMs: $0, text: text) }
        }
        return lines.sorted { $0.timeMs < $1.timeMs }
    }

    static func timestamp(_ tag: Substring) -> Int? {
        let parts = tag.split(separator: ":")
        guard parts.count == 2, let min = Int(parts[0]), let sec = Double(parts[1]) else { return nil }
        return min * 60_000 + Int((sec * 1000).rounded())
    }

    /// Index of the line being sung at `positionMs`, or nil before the first line.
    public static func currentIndex(in lines: [LyricLine], at positionMs: Int) -> Int? {
        var lo = 0, hi = lines.count - 1, found: Int?
        while lo <= hi {
            let mid = (lo + hi) / 2
            if lines[mid].timeMs <= positionMs { found = mid; lo = mid + 1 } else { hi = mid - 1 }
        }
        return found
    }

    /// Time of the next line after `positionMs`, for scheduling the next label update.
    public static func nextChangeMs(in lines: [LyricLine], after positionMs: Int) -> Int? {
        lines.first { $0.timeMs > positionMs }?.timeMs
    }
}

import Foundation

/// Lyrics from LRCLIB (https://lrclib.net), cached per Spotify track ID.
public actor LyricsService {
    let transport: HTTPTransport
    let cache: DataCache
    let now: @Sendable () -> Date
    static let base = URL(string: "https://lrclib.net/api")!
    static let notFoundTTL: TimeInterval = 7 * 24 * 3600

    public init(transport: HTTPTransport, cache: DataCache, now: @escaping @Sendable () -> Date = Date.init) {
        self.transport = transport; self.cache = cache; self.now = now
    }

    struct LRCLIBRecord: Decodable {
        let syncedLyrics: String?
        let plainLyrics: String?
        let instrumental: Bool?
    }

    struct CacheEntry: Codable {
        let synced: String?
        let plain: String?
        let storedAt: Date
    }

    public func lyrics(for track: Track) async -> Lyrics {
        let key = "lyrics:\(track.id)"
        if let entry = await cache.value(CacheEntry.self, for: key) {
            let result = Self.lyrics(synced: entry.synced, plain: entry.plain)
            let expired = result == .none && now().timeIntervalSince(entry.storedAt) > Self.notFoundTTL
            if !expired { return result }
        }
        guard let record = await fetch(track) else { return .none } // network error: don't cache
        let entry = CacheEntry(synced: record.syncedLyrics, plain: record.plainLyrics, storedAt: now())
        await cache.store(entry, for: key)
        return Self.lyrics(synced: entry.synced, plain: entry.plain)
    }

    static func lyrics(synced: String?, plain: String?) -> Lyrics {
        if let synced, case let lines = LRCParser.parse(synced), !lines.isEmpty { return .synced(lines) }
        if let plain, !plain.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty { return .plain(plain) }
        return .none
    }

    /// Exact match via `/get`; falls back to the first `/search` hit. Returns an empty record on 404.
    func fetch(_ track: Track) async -> LRCLIBRecord? {
        let artist = track.artists.first?.name ?? ""
        var get = URLComponents(url: Self.base.appendingPathComponent("get"), resolvingAgainstBaseURL: false)!
        get.queryItems = [
            .init(name: "track_name", value: track.name),
            .init(name: "artist_name", value: artist),
            .init(name: "album_name", value: track.album?.name ?? ""),
            .init(name: "duration", value: String(track.durationMs / 1000)),
        ]
        switch await request(get.url!) {
        case .ok(let data):
            if let record = try? SpotifyJSON.decoder.decode(LRCLIBRecord.self, from: data) { return record }
        case .notFound: break
        case .failed: return nil
        }
        var search = URLComponents(url: Self.base.appendingPathComponent("search"), resolvingAgainstBaseURL: false)!
        search.queryItems = [.init(name: "track_name", value: track.name), .init(name: "artist_name", value: artist)]
        switch await request(search.url!) {
        case .ok(let data):
            let hits = (try? SpotifyJSON.decoder.decode([LRCLIBRecord].self, from: data)) ?? []
            return hits.first { $0.syncedLyrics != nil } ?? hits.first ?? LRCLIBRecord(syncedLyrics: nil, plainLyrics: nil, instrumental: nil)
        case .notFound: return LRCLIBRecord(syncedLyrics: nil, plainLyrics: nil, instrumental: nil)
        case .failed: return nil
        }
    }

    enum Outcome { case ok(Data), notFound, failed }

    func request(_ url: URL) async -> Outcome {
        var req = URLRequest(url: url)
        req.setValue("Greedify/1.0 (personal macOS client)", forHTTPHeaderField: "User-Agent")
        guard let (data, http) = try? await transport.send(req) else { return .failed }
        switch http.statusCode {
        case 200..<300: return .ok(data)
        case 404: return .notFound
        default: return .failed
        }
    }
}

import AppKit
import ApplicationServices

public enum MediaKeyAction: Equatable, Sendable { case playPause, next, previous }

public enum MediaKeyDecoder {
    /// Decodes an `NSEvent.systemDefined` media-key event (subtype 8).
    /// `data1` = keyCode << 16 | keyState << 8 | repeat; keyState 0x0A = down, 0x0B = up.
    public static func decode(subtype: Int16, data1: Int) -> (action: MediaKeyAction, isDown: Bool)? {
        guard subtype == 8 else { return nil }
        let keyCode = (data1 & 0xFFFF_0000) >> 16
        let keyState = (data1 & 0xFF00) >> 8
        let action: MediaKeyAction
        switch keyCode {
        case 16: action = .playPause          // NX_KEYTYPE_PLAY
        case 17, 19: action = .next           // NX_KEYTYPE_NEXT, NX_KEYTYPE_FAST
        case 18, 20: action = .previous       // NX_KEYTYPE_PREVIOUS, NX_KEYTYPE_REWIND
        default: return nil
        }
        return (action, keyState == 0x0A)
    }
}

/// Global event tap that turns media keys into Greedify actions and swallows them,
/// so macOS never forwards them to Apple Music. Needs Accessibility permission.
@MainActor
public final class MediaKeyTap {
    public var onAction: (MediaKeyAction) -> Void
    private var tap: CFMachPort?
    private var source: CFRunLoopSource?

    public init(onAction: @escaping (MediaKeyAction) -> Void) { self.onAction = onAction }

    public static var hasPermission: Bool { AXIsProcessTrusted() }

    public static func requestPermission() {
        AXIsProcessTrustedWithOptions(["AXTrustedCheckOptionPrompt": true] as CFDictionary)
    }

    public var isRunning: Bool { tap.map { CGEvent.tapIsEnabled(tap: $0) } ?? false }

    /// Returns false if the tap couldn't be created (usually: no Accessibility permission).
    @discardableResult
    public func start() -> Bool {
        guard tap == nil else { return true }
        let mask = CGEventMask(1 << 14) // NX_SYSDEFINED
        let callback: CGEventTapCallBack = { _, type, event, refcon in
            guard let refcon else { return Unmanaged.passUnretained(event) }
            let me = Unmanaged<MediaKeyTap>.fromOpaque(refcon).takeUnretainedValue()
            if type == .tapDisabledByTimeout || type == .tapDisabledByUserInput {
                MainActor.assumeIsolated { me.reenable() }
                return Unmanaged.passUnretained(event)
            }
            guard let decoded = MediaKeyTap.decode(event) else { return Unmanaged.passUnretained(event) }
            if decoded.isDown {
                let action = decoded.action
                MainActor.assumeIsolated { me.onAction(action) }
            }
            return nil // swallow both key-down and key-up
        }
        guard let port = CGEvent.tapCreate(tap: .cgSessionEventTap, place: .headInsertEventTap, options: .defaultTap,
                                           eventsOfInterest: mask, callback: callback,
                                           userInfo: Unmanaged.passUnretained(self).toOpaque()) else { return false }
        tap = port
        source = CFMachPortCreateRunLoopSource(nil, port, 0)
        CFRunLoopAddSource(CFRunLoopGetMain(), source, .commonModes)
        CGEvent.tapEnable(tap: port, enable: true)
        return true
    }

    public func stop() {
        if let tap { CGEvent.tapEnable(tap: tap, enable: false) }
        if let source { CFRunLoopRemoveSource(CFRunLoopGetMain(), source, .commonModes) }
        tap = nil; source = nil
    }

    private func reenable() {
        if let tap { CGEvent.tapEnable(tap: tap, enable: true) }
    }

    nonisolated static func decode(_ event: CGEvent) -> (action: MediaKeyAction, isDown: Bool)? {
        guard let ns = NSEvent(cgEvent: event), ns.type == .systemDefined else { return nil }
        return MediaKeyDecoder.decode(subtype: ns.subtype.rawValue, data1: ns.data1)
    }
}

/// Quits Apple Music whenever it launches (catches AirPods/headphone buttons the tap can't see).
@MainActor
public final class MusicBlocker {
    public nonisolated static let musicBundleID = "com.apple.Music"
    public var isEnabled: Bool
    private var observer: NSObjectProtocol?

    public init(isEnabled: Bool) { self.isEnabled = isEnabled }

    public nonisolated static func shouldBlock(bundleID: String?, enabled: Bool) -> Bool {
        enabled && bundleID == musicBundleID
    }

    public func start() {
        guard observer == nil else { return }
        observer = NSWorkspace.shared.notificationCenter.addObserver(
            forName: NSWorkspace.didLaunchApplicationNotification, object: nil, queue: .main
        ) { [weak self] note in
            let app = note.userInfo?[NSWorkspace.applicationUserInfoKey] as? NSRunningApplication
            MainActor.assumeIsolated {
                guard let self, let app, Self.shouldBlock(bundleID: app.bundleIdentifier, enabled: self.isEnabled) else { return }
                if !app.terminate() { app.forceTerminate() }
            }
        }
    }

    public func stop() {
        if let observer { NSWorkspace.shared.notificationCenter.removeObserver(observer) }
        observer = nil
    }
}

/// librespot command line (spec §3, §5). Written one argument per line to an args file that
/// the bundled `greedify-speaker` launcher reads, so settings can change without re-signing the app.
public struct LibrespotConfig: Equatable, Sendable {
    public var deviceName: String
    public var bitrate: Int                 // 96, 160 or 320
    public var normalisation: Bool
    public var audioCacheLimitBytes: Int?   // nil = audio cache off
    public var systemCacheDir: URL          // credentials; never cleared by "Clear"
    public var audioCacheDir: URL

    public init(deviceName: String, bitrate: Int, normalisation: Bool, audioCacheLimitBytes: Int?,
                systemCacheDir: URL, audioCacheDir: URL) {
        self.deviceName = deviceName; self.bitrate = bitrate; self.normalisation = normalisation
        self.audioCacheLimitBytes = audioCacheLimitBytes
        self.systemCacheDir = systemCacheDir; self.audioCacheDir = audioCacheDir
    }

    public var arguments: [String] {
        var args = ["--name", deviceName, "--device-type", "computer",
                    "--bitrate", String(bitrate), "--autoplay", "on",
                    "--system-cache", systemCacheDir.path, "--cache", audioCacheDir.path]
        if normalisation { args.append("--enable-volume-normalisation") }
        if let limit = audioCacheLimitBytes {
            args += ["--cache-size-limit", "\(max(1, limit / 1_048_576))M"]
        } else {
            args.append("--disable-audio-cache")
        }
        return args
    }

    /// Arguments for the one-time interactive login (setup step 3).
    public var loginArguments: [String] { arguments + ["--enable-oauth"] }

    public var argsFileContents: String { arguments.joined(separator: "\n") + "\n" }

    public var credentialsFile: URL { systemCacheDir.appendingPathComponent("credentials.json") }
}

public enum GreedifyPaths {

    }

    }
    public static var appCache: URL { caches.appendingPathComponent("data") }
    public static var librespotSystemCache: URL { appSupport.appendingPathComponent("librespot") }
    public static var librespotAudioCache: URL { caches.appendingPathComponent("librespot-audio") }

/// Manages the librespot LaunchAgent bundled in `Contents/Library/LaunchAgents`.
@MainActor
public final class LibrespotService {
    public static let label = "com.alperen.greedify.librespot"
    let service = SMAppService.agent(plistName: "\(LibrespotService.label).plist")

    public init() {}

    public var status: SMAppService.Status { service.status }
    public var hasCredentials: Bool { FileManager.default.fileExists(atPath: GreedifyPaths.librespotSystemCache.appendingPathComponent("credentials.json").path) }

    public func writeArgs(_ config: LibrespotConfig) throws {
        try FileManager.default.createDirectory(at: GreedifyPaths.appSupport, withIntermediateDirectories: true)
        try FileManager.default.createDirectory(at: config.systemCacheDir, withIntermediateDirectories: true)
        try FileManager.default.createDirectory(at: config.audioCacheDir, withIntermediateDirectories: true)
        try config.argsFileContents.write(to: GreedifyPaths.librespotArgsFile, atomically: true, encoding: .utf8)
    }

    public func register(_ config: LibrespotConfig) throws {
        try writeArgs(config)
        if service.status != .enabled { try service.register() }
    }

    public func unregister() async throws { try await service.unregister() }

    /// Applies new settings: rewrite args and restart the agent (~1 s of silence).
    public func apply(_ config: LibrespotConfig) throws {
        try writeArgs(config)
        restart()
    }

    /// Restarts the agent; if launchd no longer knows it (booted out, unregistered), registers it again.
    public func restart() {
        let p = Process()
        p.executableURL = URL(fileURLWithPath: "/bin/launchctl")
        p.arguments = ["kickstart", "-k", "gui/\(getuid())/\(Self.label)"]
        var ok = false
        if (try? p.run()) != nil { p.waitUntilExit(); ok = p.terminationStatus == 0 }
        if !ok { try? service.register() }
    }

    /// Clears the audio cache without touching credentials, then restarts librespot.
    public func clearAudioCache(_ config: LibrespotConfig) {
        try? FileManager.default.removeItem(at: config.audioCacheDir)
        try? FileManager.default.createDirectory(at: config.audioCacheDir, withIntermediateDirectories: true)
        restart()
    }

    /// Setup step 3: runs librespot with `--enable-oauth`, opens the login URL it prints,
    /// and waits until `credentials.json` appears. Returns false on timeout.
    public func interactiveLogin(_ config: LibrespotConfig, librespotURL: URL, timeout: Duration = .seconds(300)) async -> Bool {
        try? writeArgs(config)
        let p = Process()
        p.executableURL = librespotURL
        p.arguments = config.loginArguments
        let pipe = Pipe()
        p.standardOutput = pipe
        p.standardError = pipe
        pipe.fileHandleForReading.readabilityHandler = { handle in
            let text = String(decoding: handle.availableData, as: UTF8.self)
            if let url = Self.loginURL(in: text) { Task { @MainActor in NSWorkspace.shared.open(url) } }
        }
        do { try p.run() } catch { return false }
        defer { pipe.fileHandleForReading.readabilityHandler = nil; if p.isRunning { p.terminate() } }
        let deadline = ContinuousClock.now + timeout
        while ContinuousClock.now < deadline {
            if FileManager.default.fileExists(atPath: config.credentialsFile.path) { return true }
            try? await Task.sleep(for: .milliseconds(500))
        }
        return false
    }

    public nonisolated static func loginURL(in output: String) -> URL? {
        guard let range = output.range(of: #"https://accounts\.spotify\.com/[^\s"']+"#, options: .regularExpression) else { return nil }
        return URL(string: String(output[range]))
    }
}

/// Owns every service and store; injected into views with `.environment(model)`.
@MainActor @Observable
final class AppModel {
    let settings: AppSettings
    let tokens: TokenStore = KeychainTokenStore()
    let dataCache: DataCache
    let images: ImageCache
    let lyricsService: LyricsService
    let librespot = LibrespotService()
    private(set) var api: LiveSpotifyAPI
    private(set) var player: PlayerStore
    private(set) var library: LibraryStore
    private(set) var search: SearchStore

    var route: Route? = .liked
    var showLyrics = true
    private(set) var lyrics: Lyrics = .none
    private(set) var lyricsTrackID: String?
    private(set) var menuBarLabel: MenuBarLabel = .iconOnly
    private(set) var banner: String?
    private(set) var isOffline = false
    var needsSetup: Bool { settings.clientID.isEmpty || tokens.load() == nil || !librespot.hasCredentials }

    @ObservationIgnored private var mediaKeys: MediaKeyTap?
    @ObservationIgnored private var musicBlocker: MusicBlocker?
    @ObservationIgnored private var labelTask: Task<Void, Never>?
    @ObservationIgnored private var bannerTask: Task<Void, Never>?
    @ObservationIgnored private let pathMonitor = NWPathMonitor()
    @ObservationIgnored private var started = false
    @ObservationIgnored private var observers: [NSObjectProtocol] = []

    static let redirectURI = URL(string: "greedify://callback")!
    static let log = Logger(subsystem: "com.alperen.greedify", category: "app")

    init() {
        let settings = AppSettings()
        self.settings = settings
        let transport = URLSessionTransport()
        dataCache = DataCache(directory: GreedifyPaths.appCache, limitBytes: settings.appCacheMB * 1_048_576)
        images = ImageCache(disk: dataCache, transport: transport, memoryLimitBytes: settings.artworkMemoryMB * 1_048_576)
        lyricsService = LyricsService(transport: transport, cache: dataCache)
        let api = Self.makeAPI(clientID: settings.clientID, tokens: tokens, transport: transport)
        self.api = api
        player = PlayerStore(api: api, localDeviceName: settings.deviceName)
        library = LibraryStore(api: api, cache: dataCache)
        search = SearchStore(api: api)
    }

    static func makeAPI(clientID: String, tokens: TokenStore, transport: HTTPTransport) -> LiveSpotifyAPI {
        let auth = AuthService(config: AuthConfig(clientID: clientID, redirectURI: redirectURI), transport: transport)
        return LiveSpotifyAPI(auth: auth, tokens: tokens, transport: transport)
    }

    var authService: AuthService {
        AuthService(config: AuthConfig(clientID: settings.clientID, redirectURI: Self.redirectURI), transport: URLSessionTransport())
    }

    /// Rebuilds the API client and stores after the client ID changes (setup step 1).
    func rebuildClients() {
        player.stopPolling()
        api = Self.makeAPI(clientID: settings.clientID, tokens: tokens, transport: URLSessionTransport())
        player = PlayerStore(api: api, localDeviceName: settings.deviceName)
        library = LibraryStore(api: api, cache: dataCache)
        search = SearchStore(api: api)
    }

    // MARK: Lifecycle

    /// Called once at launch and again when setup finishes.
    func start() {
        applyAppearance()
        guard !needsSetup, !started else { return }
        started = true
        try? librespot.register(settings.librespotConfig)
        player.startPolling()
        Task { await library.load() }
        startMediaKeys()
        musicBlocker = MusicBlocker(isEnabled: settings.blockAppleMusic)
        musicBlocker?.start()
        startNetworkMonitor()
        observeSystemEvents()
        observePlayer()
        observeErrors()
    }

    /// Wake from sleep: re-sync at once (the local clock and tokens may be stale).
    /// Accessibility granted later: start the media-key tap without a relaunch.
    private func observeSystemEvents() {
        let ws = NSWorkspace.shared.notificationCenter
        observers.append(ws.addObserver(forName: NSWorkspace.didWakeNotification, object: nil, queue: .main) { [weak self] _ in
            MainActor.assumeIsolated {
                guard let self else { return }
                Task { await self.player.refresh(); self.rescheduleLabel() }
            }
        })
        observers.append(DistributedNotificationCenter.default().addObserver(
            forName: NSNotification.Name("com.apple.accessibility.api"), object: nil, queue: .main
        ) { [weak self] _ in
            // The trust flag updates shortly after the notification.
            Task { @MainActor in
                try? await Task.sleep(for: .milliseconds(500))
                self?.startMediaKeys()
            }
        })
    }

    func startMediaKeys() {
        guard mediaKeys == nil, MediaKeyTap.hasPermission else { return }
        let tap = MediaKeyTap { [weak self] action in
            guard let self else { return }
            Task {
                switch action {
                case .playPause: await self.player.togglePlayPause()
                case .next: await self.player.next()
                case .previous: await self.player.previous()
                }
            }
        }
        if tap.start() { mediaKeys = tap }
    }

    var mediaKeysActive: Bool { mediaKeys?.isRunning ?? false }

    func setBlockAppleMusic(_ on: Bool) {
        settings.blockAppleMusic = on
        musicBlocker?.isEnabled = on
    }

    func applyAppearance() {
        switch settings.appearance {
        case .system: NSApp.appearance = nil
        case .light: NSApp.appearance = NSAppearance(named: .aqua)
        case .dark: NSApp.appearance = NSAppearance(named: .darkAqua)
        }
    }

    private func startNetworkMonitor() {
        pathMonitor.pathUpdateHandler = { [weak self] path in
            let online = path.status == .satisfied
            Task { @MainActor in self?.setOnline(online) }
        }
        pathMonitor.start(queue: .global(qos: .utility))
    }

    private func setOnline(_ online: Bool) {
        guard online == isOffline else { return }
        isOffline = !online
        if online { player.startPolling() } else { player.stopPolling() }
    }

    // MARK: Lyrics and menu-bar label

    /// Re-runs whenever the player state changes (poll, seek, track change).
    private func observePlayer() {
        withObservationTracking {
            _ = player.state
            _ = player.clock
            _ = settings.lyricsInMenuBar
        } onChange: { [weak self] in
            Task { @MainActor in
                guard let self else { return }
                await self.trackChanged()
                self.rescheduleLabel()
                self.observePlayer()
            }
        }
        Task { await trackChanged(); rescheduleLabel() }
    }

    private func trackChanged() async {
        guard let track = player.track else { lyrics = .none; lyricsTrackID = nil; return }
        guard track.id != lyricsTrackID else { return }
        lyricsTrackID = track.id
        lyrics = .none
        let fetched = await lyricsService.lyrics(for: track)
        if lyricsTrackID == track.id { lyrics = fetched; rescheduleLabel() }
    }

    /// Sets the label now, then sleeps until the next synced line and repeats (one timer, no polling).
    func rescheduleLabel() {
        labelTask?.cancel()
        labelTask = Task { [weak self] in
            while !Task.isCancelled {
                guard let self else { return }
                let pos = self.player.positionMs(at: Date())
                self.menuBarLabel = MenuBarLabel.make(enabled: self.settings.lyricsInMenuBar, isPlaying: self.player.isPlaying,
                                                      trackName: self.player.track?.name, lyrics: self.lyrics, positionMs: pos)
                guard self.player.isPlaying, self.settings.lyricsInMenuBar, case .synced(let lines) = self.lyrics,
                      let next = LRCParser.nextChangeMs(in: lines, after: pos) else { return }
                try? await Task.sleep(for: .milliseconds(max(50, next - pos)))
            }
        }
    }

    // MARK: Banners

    private func observeErrors() {
        withObservationTracking {
            _ = player.lastError
            _ = library.lastError
            _ = search.lastError
        } onChange: { [weak self] in
            Task { @MainActor in
                guard let self else { return }
                if let e = self.player.lastError ?? self.library.lastError ?? self.search.lastError { self.show(e) }
                self.observeErrors()
            }
        }
    }

    func show(_ error: SpotifyError) {
        Self.log.error("\(String(describing: error), privacy: .public)")
        if case .rateLimited = error { return } // shown as the menu-bar status icon instead
        showBanner(error.bannerText)
        player.clearError(); library.clearError()
    }

    func showBanner(_ text: String) {
        banner = text
        bannerTask?.cancel()
        bannerTask = Task { [weak self] in
            try? await Task.sleep(for: .seconds(5))
            if !Task.isCancelled { self?.banner = nil }
        }
    }

    var needsReauth: Bool { tokens.load() == nil && !settings.clientID.isEmpty }

    // MARK: Account

    func logOut() {
        player.stopPolling()
        tokens.clear()
        started = false
        settings.onboardingDone = false
    }

    func reset() async {
        logOut()
        try? await librespot.unregister()
        await dataCache.clear()
        images.clearMemory()
        try? FileManager.default.removeItem(at: GreedifyPaths.appSupport)
        try? FileManager.default.removeItem(at: GreedifyPaths.caches)
        settings.reset()
    }
}

/// Runs the PKCE login in the system sheet and stores the tokens (setup step 2).
@MainActor
final class SpotifyLogin: NSObject, ASWebAuthenticationPresentationContextProviding {
    private var session: ASWebAuthenticationSession?

    func logIn(auth: AuthService, store: TokenStore) async throws {
        let verifier = PKCE.makeVerifier()
        let state = PKCE.makeState()
        let url = auth.authorizationURL(verifier: verifier, state: state)
        let callback: URL = try await withCheckedThrowingContinuation { cont in
            let s = ASWebAuthenticationSession(url: url, callback: .customScheme("greedify")) { url, error in
                if let url { cont.resume(returning: url) } else { cont.resume(throwing: error ?? AuthError.missingCode) }
            }
            s.presentationContextProvider = self
            s.prefersEphemeralWebBrowserSession = false
            session = s
            s.start()
        }
        let code = try AuthService.code(from: callback, expectedState: state)
        store.save(try await auth.exchange(code: code, verifier: verifier))
    }

    nonisolated func presentationAnchor(for session: ASWebAuthenticationSession) -> ASPresentationAnchor {
        MainActor.assumeIsolated { NSApp.keyWindow ?? NSApp.windows.first ?? ASPresentationAnchor() }
    }
}

                    Text(track.artistLine).font(.caption).foregroundStyle(.secondary).lineLimit(1)
                }
            }
            .frame(maxWidth: .infinity, alignment: .leading)

        .onTapGesture(count: 2) { play() }
        .contextMenu { TrackContextMenu(track: track, context: context, onPlay: play, onNewPlaylist: { newPlaylistFor = track }) }
        .sheet(item: $newPlaylistFor) { NewPlaylistSheet(track: $0) }
    }

    func play() {
        Task {
            if let uri = context.contextURI {
                await model.player.play(.context(uri, startingAt: track.uri))
            } else {
                let uris = list.map(\.uri)
                let start = uris.firstIndex(of: track.uri) ?? 0
                await model.player.play(.tracks(Array(uris[start...].prefix(100))))
            }
        }
    }
}

                    Button("Clear") { model.librespot.clearAudioCache(settings.librespotConfig); Task { await measure() } }
                }
            }
            .onChange(of: settings.audioCacheGB) { try? model.librespot.apply(settings.librespotConfig) }

            HStack {
                Spacer()

                    Task {
                        await model.dataCache.clear(); model.images.clearMemory()
                        model.librespot.clearAudioCache(settings.librespotConfig)
                        await measure()
                    }
                }
            }
            Text("Clearing never logs you out. Clearing the audio cache restarts the Mac speaker for about a second.")
                .font(.caption).foregroundStyle(.secondary)
        }
        .formStyle(.grouped)

    func measure() async {
        appCacheBytes = await model.dataCache.sizeBytes()
        audioCacheBytes = Self.directorySize(GreedifyPaths.librespotAudioCache)
    }

    static func directorySize(_ url: URL) -> Int {
        guard let e = FileManager.default.enumerator(at: url, includingPropertiesForKeys: [.fileSizeKey]) else { return 0 }
        var total = 0
        for case let f as URL in e { total += (try? f.resourceValues(forKeys: [.fileSizeKey]).fileSize) ?? 0 }
        return total
    }

    func bytes(_ n: Int) -> String { ByteCountFormatter.string(fromByteCount: Int64(n), countStyle: .file) }

open /Applications/Greedify.app

#!/bin/sh
# Physical footprint of Greedify + librespot.
# Spec §1 target: <= 70 MB total while playing with the main window closed. Exits 1 above target.
footprint -f bytes -p Greedify -p librespot 2>/dev/null | awk '
  /\[[0-9]+\]:.*Footprint:/ {
    for (i = 1; i <= NF; i++) if ($i == "Footprint:") { mb = $(i + 1) / 1048576; printf "%-28s %7.1f MB\n", $1 " " $2, mb; total += mb }
  }
  END { printf "%-28s %7.1f MB (target 70 MB)\n", "TOTAL", total; exit (total > 70) }'
```
